# Student Performance Analysis

## Data Analytics Mini Project – CA3

### Objective
To analyse student examination performance, explore factors associated with exam scores, and predict mathematics scores using R.

### Dataset
Students Performance in Exams – Kaggle:
https://www.kaggle.com/datasets/spscientist/students-performance-in-exams

Download the dataset and place `StudentsPerformance.csv` in the same folder as the R script.

### Tools and Packages
- R programming
- RStudio / Posit Cloud
- ggplot2
- dplyr
- GitHub

### Analysis Performed
1. Data loading and inspection
2. Data cleaning and feature creation
3. Exploratory data analysis
4. Data visualisation
5. Hypothesis testing (t-test, chi-square, correlation and ANOVA)
6. Linear regression to predict mathematics scores
7. Model evaluation using RMSE, MAE and R-squared

### How to Run
1. Open the project in RStudio or Posit Cloud.
2. Upload `StudentsPerformance.csv` into the project folder.
3. Install the packages once using:
   `install.packages(c("ggplot2", "dplyr"))`
4. Open `Student_Performance_Analysis.R` and run the script.
5. The script saves graphs in the `plots` folder.

### Results
Add your actual statistical test results and regression metrics here after running the script. Do not enter guessed values.

### Limitations
- The analysis uses one dataset.
- Correlation does not prove causation.
- The model uses the available student and subject-score variables only.
